## About Me

I'm a **Full-Stack Web Developer with a backend-oriented profile** and a Bachelor's Degree in Business Informatics from the **University of Costa Rica**.

I currently work on the development of an **electronic invoicing platform**, contributing across backend, frontend, database and API layers. My work involves implementing business logic, designing and integrating APIs, working with relational databases, developing user-facing features and maintaining existing application functionality.

My main professional stack includes **PHP, Laravel, Vue 3, TypeScript, JavaScript, MySQL and RESTful APIs**.

I enjoy understanding how systems work beyond individual features, analyzing existing application flows and building maintainable solutions using structured architectures and development practices.

I work in collaborative development environments using **Git, feature branches, pull requests, code reviews, testing and technical documentation**.
